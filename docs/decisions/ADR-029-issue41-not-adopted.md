# ADR-029: (漫画) 曖昧さ回避記事でのmediamixチェック緩和（Issue #41）を採用しない

- 日付：2026-09-25
- 状態：採用

## 背景

Issue #41は、記事名が`(漫画)`曖昧さ回避表記である場合に`_is_novel_primary()`の
mediamix主語チェックを緩め、原作小説の存在を理由に判定不能へ落ちるケース
（陰陽師の偽陰性）を救う変更を提案している。Issue #41自身が「fail-closedを緩める
方向の変更であり、偽陽性リスクを増やす」「他の派生Issue（#35から派生した
`ONGOING_RE`誤爆・`COMPLETED_STRONG_RE`の「一話完結」誤爆・`COMPLETED_WEAK_RE`の
連載開始文誤爆・採用経路のログ出力、すなわち#36〜#39）が完了したあとに着手を
検討すること」と自ら着手順序を限定している。

前提となる#36〜#39は4件とも既にCLOSED済みである。着手順序上の制約は解消している。

しかし、着手順序が整った後の再調査（作業79-81、Issue #41への2026-08-12付コメント）
は、本Issueが対象とする`is_novel_primary`のmediamix偽陰性に該当する行を
`direct_disambiguation`経由30件のパイロット標本から**実測で0件**と報告している
（「緩和が影響しうる行: 0件」）。これは陰陽師1件を除けば、本Issueの提案を
実データで裏付ける行が他に見つからなかったことを意味する。

## 決定

**Issue #41（`(漫画)`曖昧さ回避記事でのmediamixチェック緩和）を採用しない。**

## 検討した案と棄却理由

- **採用し、記事名が`(漫画)`で終わる場合に限定してmediamix主語チェックを緩和する案**:
  棄却。作業79-81の実測で対象行が0件（陰陽師1件のみが既知の裏付け）であり、
  緩和の効果を確認できる材料が実データ上に無い。Issue #41本文が挙げる、特定の
  回帰ケース（原作小説完結・漫画連載中のパターン）を壊すリスクと引き換えに得られる
  実利が、現時点の実測では確認できない。
- **現状維持（Issue #41をOPENのまま、判断を保留する）**: 棄却。着手順序の前提
  （#36〜#39）は完了しており、再調査（作業79-81）も済んでいる。判断を確定させる
  材料は既に揃っており、先送りする理由がない。

## 決定の理由

- 作業79-81の実測で、本Issueのスコープに該当する行が0件だった。緩和を実装しても
  適用対象がほぼ存在しないため、便益が確認できない。
- fail-closed原則（Issue #8・#9以来: 無関係な記事を確信を持って誤答するより
  判定不能を優先する）に照らすと、対象行がほぼ無い状態で偽陽性リスクを増やす方向の
  変更を採用する理由がない。
- Issue #41本文が明示する回帰リスク（`_is_novel_primary()`のmediamixチェックが
  守っている、特定の回帰ケース——原作小説完結・漫画連載中のパターン——を壊す危険）
  は、対応する回帰テスト（`tests/test_wikipedia_client.py`）で現在も守られている。
  実利が確認できない変更のためにこのリスクを取る理由がない。

## 帰結

- **本ADRはIssue #41を却下する。** 今後、緩和で判定不能から正答（完結/連載中）に
  変わる実例を、既知の1件（陰陽師）とは独立した実データで複数件得て、事前登録を
  行ったうえで再検討する。それまでは`_is_novel_primary()`の現行挙動を変更しない。
- 作業79-81のコメントが挙げた副産物のテーマ（テーマA: 単一文内の掲載誌移籍
  パターン、テーマB: `COMPLETED_WEAK_RE`/`ONGOING_RE`の「連載」限定語彙）は、
  いずれも本Issue（mediamix偽陰性）とは別テーマであり、本ADRの対象外である。
  なお、これらは「未起票のまま」ではなく、コメント時点（2026-08-12）から本ADR
  作成までの間にそれぞれIssue #134・Issue #135として個別に起票され、いずれも
  CLOSED済みであることを確認した。

# ADR-033: 定型手順のスキル化（replace-doc-range・publish-github・pre-push-check）

- 日付：2026-09-28
- 状態：採用

## 背景

指示ブロックで毎回書いていた定型手順（既存文書の行範囲の置き換え、Issue・PR の
作成と確認、push 前の検証）がスキルになっていなかった。Issue #345 では、置き換え
対象の範囲の想定違いを、現行部分の一致確認で止められた。

## 決定

1. 次の3つのスキルを `.claude/skills/` に追加する。いずれも、指示で確定した値・
   本文を使う手順書とし、本文の作成・方針の判断はしない。
   - replace-doc-range：既存文書の行範囲の置き換え
   - publish-github：Issue・PR の作成と本文の確認
   - pre-push-check：push 前の検証
2. 3つともクラウドとローカルの両方で動く書き方にする。GitHub の作成・更新は
   GitHub MCP のツールを優先し、なければ gh api（REST）を使う。確認のための取得は
   常に gh api（REST の GET）で行う（ADR-030）。
3. 帰属フッタの扱いは ADR-030 に従う。作品名照合は ADR-031 に従い、追加した行・
   本文だけを照合する。
4. マージ後、ユーザが `settings.json` の `deny` に3つの SKILL.md の Edit・Write を
   追加する。
5. work・decompose スキルは変更しない（GraphQL を使う gh のサブコマンドを使うため、
   クラウドでは動かない可能性がある。未確認）。

## 影響

指示ブロックは、スキル名と、範囲・本文などの値の指定で済む。スキルの手順を
変えるときは、ユーザが手動で編集する。

# ADR-032: 調査役・監査役サブエージェントの定義

- 日付：2026-09-27
- 状態：採用

## 決定

1. 調査役（investigator）と監査役（auditor）を `.claude/agents/` に定義する。
   ツールは Read・Grep・Glob に限り、読み取り専用とする（役割分離を人格ではなく
   権限の差で行う。ADR-030 決定2）。
2. 監査役の指摘は所在・観点・確度・根拠を必須とし、所在と観点を示せない指摘は
   しない。修正案・採否の判断は書かない。
3. 監査役の観点は report-self-check の手順3を唯一の出典とし、定義ファイルに
   書き写さない（ADR-031 決定7）。
4. 調査役は材料の列挙だけを行い、判断・推奨をしない。確かめていないことは
   推測と明記する。
5. 両エージェントとも Bash を持たないため、git の履歴・GitHub の情報・
   スクリプトの実行が必要な調査は呼び出し元が行う。
6. マージ後、ユーザが `settings.json` の `deny` に `.claude/agents/**` を追加する。

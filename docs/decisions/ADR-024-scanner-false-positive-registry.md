# ADR-024: 走査器の偽陽性の事前登録簿と定期走査の方針

- 日付：2026-09-18
- 状態：採用

## 文脈

走査器（`scripts/check_no_personal_info.py`）は手動運用である（ADR-017）。
verify.sh・CIのゲートにはなっていない。

全追跡ファイルへの走査は、これまで一度も実施されていなかった。ADR-017の
「除去すべき個人情報は0件」は追跡ファイル22件を対象とした測定であり、
全追跡ファイルを対象としたものではなかった。

実施したところ、実在のユーザ名を含む検出が6件あった（Issue #288、PR #289で
除去済み）。

実測日: 2026-09-18。以下はすべて本ADR作成のために実行したコマンドの出力である。

（全追跡ファイルへの走査、パターン種別ごとの集計。実ホームディレクトリの
パスは`os.path.expanduser("~")`で実行時に取得し、検出行にその文字列が
含まれるかで真陽性を判定した）:

```
total_hits 798
files_with_hits 51
home-path 25
email 11
honorific 762
real_home_hits 0
```

検出総件数798件、検出ファイル件数51件。パターン種別ごとの件数はhome-path型
25件、email型11件、honorific型（敬称型）762件。実ホームディレクトリのパスを
含む検出は0件であり、PR #289での除去後は真陽性が残っていないことを確認した。

敬称型の検出が大半を占め、その原因は本プロジェクトの取扱対象が作品名で
あることに由来する構造的なものである（Issue #271）。

## 決定

1. **Issue #271の対処として、既知の偽陽性を事前登録簿で抑制する方式を採る。**
   走査器のパターンと除外語彙は変更しない。
2. **Issue #288の決定2として、履歴の書き換えは行わない。**
3. **Issue #288の決定3として、全追跡ファイルへの走査を定期的に行う運用を
   設ける。**

## 決定1の根拠と、採らなかった選択肢

- **除外語彙を個別に追記し続ける方式（現行の運用）**: 本プロジェクトが今後も
  作品名を大量に扱い続けるという性質の下で、一覧は際限なく増え続け、追記の
  運用コストが線形に積み上がる。採らない。
- **検出パターンを絞る方式**: ADR-017が既に「誤検出を大幅に減らせる境界条件は
  存在するが、同じ条件が実在人名の典型形も同時に除去してしまう。誤検出と
  検出漏れがパターン側では分離できない」と結論づけている。今回の真陽性6件は
  1文字＋敬称とは異なる形（home-path型）だが、パターンを絞る一般論として、
  検出範囲を狭める行為そのものが未知の真陽性を見逃す危険を増やす。採らない。
- **走査対象のファイル・ディレクトリを限定する方式**: 今回の真陽性6件は、
  まさにデータ生成物が集中するディレクトリ（`docs/holdout_measurement_2026-08/`
  配下）に存在した。偽陽性が集中するディレクトリを走査対象から除外すると、
  同じ種類のディレクトリに存在する真陽性を見逃す危険が増える。採らない。
- **現状維持（毎回全件を人間が判断する）**: 追加の実装コストはゼロだが、
  Issue #271の実例が示すとおり、投稿前走査のたびに人間の判断コストがかかり、
  作業が反復して止まる事例が今後も発生し続ける。今回のように全追跡ファイルを
  対象とした走査を実施すると798件を人間が都度判断することになり、持続可能
  でない。採らない。

## 決定1の設計要件（実装は別途）

- 登録簿は、ファイルと行の対応を記録する。走査器本体は変更しない。
- 登録簿に載っていない検出は、これまでどおり人間が判断する。
- ファイルが更新されて行がずれた場合に、登録が陳腐化したことを検出できる
  必要がある（行番号だけに依存しない同定手段が要る）。
- 登録簿自体の陳腐化を検査する手段が要る。これはIssue #286が扱う棚卸し
  文書の陳腐化と同じ構造の問題である。

## 決定3の設計要件（実装は別途）

- 実行契機（定期・リリース前・PR前のいずれか）は本ADRでは決めない。
- 対象はgit追跡ファイル全件とする。
- 実行結果の件数を記録し、前回からの増減が分かる形にする。

## ADR-017・ADR-023との関係

- ADR-017の手動運用という決定自体は維持する。本ADRはその運用を補う。
- ADR-023が記録した「走査器の検出範囲の外側は検出結果から見えない」という
  制約は、決定1では変わらない（検出範囲を狭めないため）。
- ADR-017の本文は書き換えない。

## 範囲外

- 事前登録簿の実装。
- 定期走査の実装と実行契機の決定。
- 走査器の実装変更。

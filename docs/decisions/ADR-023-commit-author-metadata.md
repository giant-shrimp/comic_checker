# ADR-023: コミットのauthorメタデータに現れる個人情報の扱い

- 日付：2026-09-18
- 状態：採用

## 文脈

コミットのauthor / committerは走査器（`scripts/check_no_personal_info.py`）の
対象外である。走査器はファイル内容のみを見ており、コミットのメタデータは
走査しない。

実測日: 2026-09-18。以下はすべて本ADR作成のために実行したコマンドの出力である。

（`git rev-list --count HEAD`）:
```
565
```

（`git rev-list --count --merges HEAD`）:
```
203
```

（`git log --merges --format='%cn' | sort | uniq -c`）:
```
    203 GitHub
```

（`git log --no-merges --format='%cn' | sort | uniq -c`）:
```
    362 giant-shrimp
```

コミット総数は565件であり、うちマージコミット（committerがGitHub）が203件、
非マージコミット（committerがハンドル名）が362件である。マージコミットの
author名には、GitHubアカウントのプロフィール表示名がGitHub側で埋め込まれる。
PRのマージを人間がGUIで行う運用（ADR-001）である以上、マージのたびに1件
増える。非マージコミットのauthor名はハンドル名であり、この問題は生じていない。

プロフィール表示名はアカウントのプロフィール画面で誰にでも見える公開情報で
ある。同じ機構により、同一アカウントのpublicリポジトリのマージコミットにも
同じ値が入っている。

## 決定

1. **過去のマージコミットの履歴書き換えを行わない。**
2. **`.mailmap`を導入しない。**
3. **増加の停止は、GitHubアカウントのプロフィール表示名の変更によって行う。**
   これはリポジトリ側の操作ではなく、オペレータがGitHubのGUIで実施する。
4. **`CLAUDE.md`の個人名禁止規則の適用範囲を明文化する。**

## 根拠

- **秘匿性**: 当該の値は既に公開情報であり、privateリポジトリの履歴を
  書き換えても秘匿性は回復しない。
- **代償**: マージコミットを書き換えると以降の全コミットハッシュが変わる。
  ADR・事前登録文書・PR本文が記録しているHEADハッシュによるロックがすべて
  無効になり、検証可能性が失われる。
- `.mailmap`はgitのコマンド出力の表示のみを変え、GitHubの画面表示には
  影響しない。対処したという記録だけが残り実態は変わらないため、採らない。

## ADR-017の主張範囲の訂正

- ADR-017の「実際に除去すべき個人情報は0件（全件が誤検出）」は、走査器の
  検出範囲内に限った主張である。
- 走査器の検出対象は3種であり、敬称を伴わない氏名の形と、コミットの
  メタデータはいずれも対象外である。
- 実際に、手動の文字列検索により走査器が検出しない個人名がファイル内容に
  1件存在することが判明している（Issue #284）。
- ADR-017の本文は書き換えない。本ADRがその主張範囲を限定する。

## 走査器を拡張しない理由

- 敬称を伴わない氏名を一般に検出する手段は存在しない。
- 人名らしさで判定する方式は誤検出を大幅に増やす。走査器の誤検出は既に
  Issue #271として起票されており、投稿前走査の運用を反復して止めている。

## 範囲外

- Issue #284が問う事前登録文書の扱い（別途Issue #284で決める）。
- publicリポジトリ側の履歴。

## 決定3の採否（2026-09-18 追記）

決定1・2・4は実施済みである。

決定3（GitHubアカウントのプロフィール表示名の変更）は、オペレータの判断により
**採用しない**。

したがって、マージコミットのauthor名への当該値の混入は今後も継続する。PRを
GUIでマージするたびに1件増える。

追記時点の実測値（`git rev-list --count HEAD`・`git rev-list --count --merges HEAD`・
`git log --merges --format='%cn' | sort | uniq -c`・
`git log --no-merges --format='%cn' | sort | uniq -c`）:

```
568
204
    204 GitHub
    364 giant-shrimp
```

コミット総数は568件であり、うちマージコミットが204件、非マージコミットが364件
である。本ADR本体に記録した値（総数565・マージ203・非マージ362）との差は、
総数+3・マージ+1・非マージ+2である。

この記録の目的は、本ADRの決定3を「実施済み」と誤読させないことである。決定3の
文言そのものは書き換えていない。

採用しない判断の帰結として、増加を許容する。当該の値が既に公開情報であることが
根拠であり、これは「根拠」節と同じ理由である。

## 4. 起きた問題と知見

- 下調べの指示で、サブエージェントの結果が観測の途中に届く場合を分岐に入れていなかった（指示側の誤り）。司令塔は分岐に当てはまらないとして止まった。
- 司令塔のターンが続いている間は、最終応答のメッセージと完了通知が届いて処理された。再開しない問題は、応答を終えた後に限って起きている。
- ListAgents は実行中のサブエージェントを running で示し、完了すると表示しない。完了と停止の区別、停止・失敗のときの表示は未確認。
- ユーザの合図の承認画面の欄が埋まっていなかった。司令塔は推測せず未決の点として残し、ユーザが後から申告した。
- 司令塔の自己点検の下書きのパスに、実装役の下書きが残っていた。司令塔は読んでから上書きし、衝突は起きなかった（P1）。
- 実装役の時間が長かった。承認画面の待ち時間を含むと見られる（推測）。
- 実装役の実績：起動1回、ハーネスのツール呼び出し35回、約344秒、トークン29909。拒否なし。

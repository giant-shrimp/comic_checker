# 走査器の偽陽性事前登録簿

本文書は、走査器（`scripts/check_no_personal_info.py`）が検出する既知の偽陽性を
記録する登録簿である（ADR-024決定1の実装、Issue #271の解消）。走査器そのものは
変更しない。`scripts/check_scanner_registry.sh`がこの登録簿を読み、走査器の
検出結果と突き合わせて、登録済みの偽陽性のみを抑制する。

## 収録する情報

各行は「ファイル・ハッシュ・型・理由」の4項目を持つ。行番号は記録しない
（ファイルの追記・剪定で陳腐化するため、ADR-024決定1の設計要件）。ハッシュは
検出された行の内容全体をSHA-256でハッシュ化し、先頭16桁（64ビット）に
切り詰めたものである。実在の個人名・作品名・敬称そのものは、この文書には
一切書かない（ADR-022の運用規約）。

## 更新方法

- **新しい偽陽性が判明したとき**: `scripts/check_scanner_registry.sh`が
  「未登録検出」として報告するファイル・ハッシュ・型を確認し、内容を
  人間が確認した上で、この表に1行追加する。真陽性の場合は登録せず、
  該当箇所を修正する。
- **登録済みの項目が陳腐化したとき**（該当行の内容が変わり、同じハッシュで
  検出されなくなったとき）: `scripts/check_scanner_registry.sh`が
  「陳腐化登録」として報告する。該当行を表から削除する。
- 行番号でのハードコードは行わない。

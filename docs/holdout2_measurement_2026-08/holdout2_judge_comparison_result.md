## 3. 項目5: 予測と実測の対比

### 3-1. 上位事前登録 `prereg_corpus_expansion_holdout2.md` 4節

## 4. Issue #157 の2語の影響件数（実測のみ。基準への該当判定は本文書では行わない）

`step99b`・`step99c` は同一の差し替えパターン（既存パターンへ対象語を選択肢として
追加するだけの最小変更）を用いている。`step99c` は `step99b` からパターンを import しており、
文字列は重複定義していない。

| 語 | 既存160件 | holdout2 119件 | 累計 |
|---|---|---|---|
| 配信終了 | 1（亡装遺体ネクロマン: 判定不能→完結） | 0 | 1 |
| 連載されており | 1（ヤリチン☆ビッチ部: 判定不能→連載中） | 1（大人にゃ恋の仕方がわからねぇ!: 判定不能→連載中） | 2 |

holdout2 側の1件は E_missed→A_correct（取りこぼしの解消）であり、
新たな誤りを生んでいない。既存160件側の2件も、いずれも判定不能からの変化である。

`prereg_v2_effective_count_basis.md` が定める基準への該当判定は、
基準の条件文を確認したうえで別途行う。本文書では実測値のみを記録する。

## 5. 限界と留保

1. **ベースライン85.0%は別標本の値**。`step98_b_compare_result.md` の A_correct 85/100 は
   sample100 に対する測定であり、holdout2 119件との同一標本前後比較ではない。
   4(b)・3(b) の対比はこの差を含んだままの比較である。
2. **期待ラベル自体が誤りうる**。v4再スポットチェックで20件中2件が人手と不一致だった。
   一致率85.7%はラベル誤りを含んだ値である。
3. **4(a) が外れた原因は本測定からは特定できない**。既存160件が curated な regression61 を
   含み母集団を代表していない可能性は説明候補のひとつだが、本測定はそれを検証していない。
   **判定不能**として記録する。「標本組成の差である」と断定しない。
4. `matched_title` が null の1件は集計から除外している。119件は記事あり件数であり、
   holdout2 の全体（120件）ではない。

## 使用した正規表現・判定ロジック（wikipedia_client.pyからの書き写し）

```python
SPINOFF_MARKERS = ("番外編", "スピンオフ", "外伝", "次世代編", "続編")
MANGA_MARKERS = ("漫画", "コミカライズ", "コミック版", "漫画版")
NOVEL_MARKERS = ("小説", "ライトノベル")
ONGOING_RE = re.compile(r"連載中(?!から|は|に|作品|の[0-9０-９]|だっ|であっ|断|、)|連載されている")
COMPLETED_STRONG_RE = re.compile(r"(?<![話回未])完結(?!させ|し(?:ていな|な)い|せず|する回)")
COMPLETED_WEAK_RE = re.compile(
    r"連載(?:が|を)?終了(?:した)?|連載された|まで[^。、]{0,20}?連載(?:された)?|打ち切(?:り|られ)"
    r"|配信された"
)
CONTINUATION_VETO_RE = re.compile(r"継続|再開|引き続き|連載を?続け|掲載を?続け")
MIGRATION_SAME_SENTENCE_RE = re.compile(
    r"(?:連載(?:が|を)?終了(?:した)?|連載された|まで[^。、]{0,20}?連載(?:された)?)"
    r"[^。]{0,30}?(?:のち|その後|後)[^。]{0,30}?"
    r"(?:連載中(?!から|は|に|作品|の[0-9０-９]|だっ|であっ)|連載されている)"
)
_PRIMARY_TYPE_RE = re.compile(r"日本の([^、。]+)")
ONGOING_FIELD_MARKER = "連載中"
HIATUS_MARKER = "休載"
END_FIELD_NAMES = ("終了号", "終了日", "終了")
```

`_judge_extract()`相当ロジックは`wikipedia_client.py` L652-704を、`_has_ongoing_signal()`
相当は同L632-634を、`_judge_via_infobox()`のEND_FIELD_NAMES走査順（先頭から非空欄の
最初のフィールドで決着）はL849-889を、それぞれ目視で再実装した。系統3・4の仮想語彙は
`extra_ongoing_literals`（ONGOING_RE候補として単純部分一致で追加）または
`extra_weak_literals`（COMPLETED_WEAK_RE候補として同様に追加）というオプション引数で
差し込めるように拡張し、`CONTINUATION_VETO_RE`によるキャンセル・`has_ongoing_elsewhere`
veto・`MIGRATION_SAME_SENTENCE_RE`・SPINOFF_MARKERSスキップ・is_multimedia/MANGA_MARKERS
ゲートは、追加語彙の有無に関わらず既存ロジックのまま適用した。

## 必要母数の逆算

計算式: 必要母数 = 10 / (影響件数 / 160)。区間推定は影響率のWilson score区間
（95%信頼区間、z=1.96）を影響件数/160に対して計算し、その下限・上限を10で除して
必要母数の区間に変換した（影響率が高い側の信頼区間端点 → 必要母数の下限、
影響率が低い側の端点 → 必要母数の上限、という対応）。

| 系統・語彙 | 影響/160 | 影響率 | 95%CI（影響率） | 必要母数・点推定 | 必要母数・95%区間 |
|---|---|---|---|---|---|
| 案B「続編」（機構別） | 2/160 | 0.0125 | [0.0034, 0.0444] | **800** | [225, 2912] |
| 系統3「配信終了」 | 1/160 | 0.0063 | [0.0011, 0.0345] | **1600** | [289, 9057] |
| 系統3「連載されており」 | 1/160 | 0.0063 | [0.0011, 0.0345] | **1600** | [289, 9057] |
| 系統3「連載され、」 | 2/160 | 0.0125 | [0.0034, 0.0444] | **800** | [225, 2912] |
| 系統4「発行されている」 | 2/160 | 0.0125 | [0.0034, 0.0444] | **800** | [225, 2912] |
| 系統4「隔年連載」 | 1/160 | 0.0063 | [0.0011, 0.0345] | **1600** | [289, 9057] |
| 系統4「書籍化された」 | 3/160 | 0.0187 | [0.0064, 0.0537] | **533** | [186, 1563] |
| 系統2「？」 | 1/160 | 0.0063 | [0.0011, 0.0345] | **1600** | [289, 9057] |

**数値の不確かさについての注記**: 分子（影響件数）がいずれも1〜3件と極めて小さいため、
95%信頼区間は非常に広い（必要母数の上限は最大で9057件に達する）。点推定値は
「最も尤もらしい一点」に過ぎず、真の必要母数がその何倍にもなる可能性を区間が
示している。点推定のみを見て判断しないこと。

**点推定ではすべての語彙が262件（残存プール全体）でも150件（実行計画上限）でも

262件で理論上到達しうるのは8語彙中4語彙（続編・連載され、・発行されている・
書籍化された）にとどまり、いずれも150件の実行計画上限は例外なく超過する。

## 走査の限界（この方法では検出できないもの）

- **系統5は原理的に対象外**（上述のとおり）。
- **系統4「短編漫画」は定義不能**（既存regexへの当てはめが成立しないジャンル語推論のため）。
- 系統3・4の仮想語彙は、単純な部分一致（`extra_ongoing_literals`/`extra_weak_literals`）
  としてのみ試験した。実際に採用されうる正規表現の形（活用形・前後の文脈条件等）が
  この単純な部分一致と異なる場合、影響件数の実測値は変わりうる。特に「連載され、」は
  ドラフト文書で「素朴な追加は安全でない」と明記されており、影響件数2件はあくまで
  「単純に追加した場合」の数値であり、安全性を検証したものではない。
- 案Bの「陰陽師」の予測（インフォボックス完結の採用）は、`_judge_via_infobox()`本体を
  一切呼ばずに、その分岐ロジック（L849-889）を目視で読んでEND_FIELD_NAMES走査順・
  ONGOING_FIELD_MARKER/HIATUS_MARKER非該当・`_is_novel_primary`veto不発火を手計算で
  確認した予測であり、実行して確認したものではない。
- 母数はholdout99+regression61の160件のみ。N=50（seed=517、未取得）は一切含まない
  （取得していないため）。
- 影響件数の分子が1〜3件と小さいため、Wilson区間はあくまで二項分布を仮定した近似であり、
  この160件という母集団自体が真にランダムな独立標本かどうか（発見材料としての
  既使用は`holdout_pool_consumption_ledger.json`が管理しているが、統計的な代表性の
  保証はもとより無い）という限界もある。

## 結論

**停止条件2に該当する。** 影響件数に基づいて必要母数を逆算した結果、点推定では
系統2〜5・案Bのすべての測定可能な語彙・パターンが、残存プール262件（実行計画上限
150件）を使っても、事前登録した最低影響件数「10件」に到達しない。

この結果は、事前登録した基準（最低10件）そのものの見直しが必要であることを示す。
**基準の変更案はここでは作成しない**（指示に従い、判断はユーザに委ねる）。

## 背景

ラベル規則v3のR5（第1部完結後の散発的掲載）には対応するコード実装が一切無い。
v3自身の`code_behavior`欄に既知の欠落として明記されている
（`docs/holdout_measurement_2026-08/step98_a_labeling_rules_v3.json`、
作業98-A-1監査時点）。

## 実測されている影響

**D_error 1件**（パチスロひとり旅、
`docs/holdout_measurement_2026-08/step98_b_compare_result.md` No.47）。

実測: 本文に「2018年7月に発売された『別冊パチスロパニック7』2018年9月号
において...18年間続いた連載が終了した。」という明示的終了宣言があり、
`judge()`は`COMPLETED_WEAK_RE`で正しく拾い完結と判定した。しかし本文はその後
「連載終了後は...不定期で読み切りや短期集中連載の形式で...新作が掲載されている」
と続き、直近12か月以内（2025年10月、コラム連載開始）の活動実績がある。ラベル
規則v3のR5はこのパターンを連載中に倒すが、コードにはこの判定を行う仕組みが無い。

## 現コーパスでの判別力

**単純な語彙一致では判別力を測定できない**（本パターンは「完結宣言」＋「散発
掲載列挙」＋「直近12か月以内の活動」の3条件の組み合わせであり、単一語彙の
出現件数に還元できない）。参考として隣接語彙（「不定期」「読み切り」
「短期集中連載」）の母数160での出現件数は9〜18件だが、これは条件の一部の
代理指標に過ぎない。

**判別力の測定方法自体は`docs/code_defects_2026-08/corpus_expansion_design.md`
「作業3」で設計したが、実データでの該当件数は262件プールを取得しなければ
測定できず、現時点では推定不能。**

ラベル規則v3のR5自体、実データ1件（パチスロひとり旅）のみを根拠に策定されて
おり、規則の一般化可能性も未確認。

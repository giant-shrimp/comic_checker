# 系統4-B（「書籍化された」）棄却記録

Issue: #158
判定日: 2026-08-21
判定: **棄却（実装しない）**
調査時 main: 78a9959

## 1. 結論

`COMPLETED_WEAK_RE` への「書籍化された」追加は**採用しない**．
件数基準（有効ヒット2件以上）は満たすが，変化3件のうち2件が誤判定を新規に生む悪化方向であり，
正味の効果が負であるため．

## 2. 実測結果

対象コーパス: 保存コーパス160件（regression 61 + holdout 99）
導出: `docs/regression_corpus_2026-08/step98_judge_harness.py` の `run_judge_with_snapshot()` を用い，
`COMPLETED_WEAK_RE` をプロセス内で差し替えて before/after を比較（ファイル書き込みなし）

| 指標 | 値 |
|---|---|
| 出現件数 | 3 |
| 有効ヒット件数 | 3 |
| 無効化により有効ヒットに至らなかった件数 | 0 |
| 改善 | 1 |
| 悪化 | 2 |
| コーパス全件走査での想定外の副作用 | 0 |

### 変化した3件

| corpus | タイトル | before → after | 期待ラベル | 分類 |
|---|---|---|---|---|
| holdout | ゴーストワールド (コミック) | 判定不能 → 完結 | 完結 | 改善（E_missed解消） |
| holdout | うちのトコでは | 判定不能 → 完結 | 連載中 | **悪化** |
| regression | 姫騎士がクラスメート！　ＴＨＥ　ＣＯＭＩＣ | 判定不能 → 完結 | 判定不能 | **悪化** |

「うちのトコでは」の期待ラベルは confused=True（`confused_conditions=['c']`）である．

## 3. 悪化の構造

いずれも「作品全体の連載終了」ではなく「一部の掲載分・派生作品が単行本になった」事実を
誤って完結根拠として拾っている．

- うちのトコでは: 特定年の掲載分が単行本に収録された旨の記述．作品全体は継続中．
- 姫騎士がクラスメート！　ＴＨＥ　ＣＯＭＩＣ: 原作小説のコミカライズが書籍化された旨の記述．
  漫画本編の連載状況とは無関係．

これは系統3 Phase C の「発売された」，系統4-A Phase C の「刊行されている」で観測された
「単発の刊行・収録言及を完結根拠として誤採用する」構造的リスクと**同型**である．

## 4. veto 機構が救済しなかった理由

`_judge_extract()` が備える無効化機構（CONTINUATION_VETO_RE，has_ongoing_elsewhere，
MIGRATION_SAME_SENTENCE_RE，同一文内 tie，SPINOFF_MARKERS，is_multimedia ゲート）は
いずれもこの2件を救済しなかった．

- うちのトコでは: 本文中に `ONGOING_RE` 一致文が存在しないため `has_ongoing_elsewhere=False`．
  該当作品の継続を示す表現「隔年連載となっている」は現行 `ONGOING_RE` に一致しない．
- 姫騎士がクラスメート！　ＴＨＥ　ＣＯＭＩＣ: 冒頭文に「漫画」を含むため `_is_novel_primary()` が False となり，
  is_multimedia ゲートを回避して当該文が決着文として採用される．

## 5. 得られた知見

1. **件数基準の充足は安全性を意味しない．** 有効ヒット件数はスコープ判定の入口条件にすぎず，
   変化方向の内訳（改善／悪化）を分離して評価しなければ採否は決められない．
2. **同一機構への追加であっても語彙ごとの実データ検証が必須である．**
   系統4-A 事前登録6節が「刊行されている」に対して行った注意喚起が，
   本件「書籍化された」自体で的中した．
3. **「刊行・発売・収録」系の語彙は構造的に危険である．**
   作品全体の完結ではなく個別の刊行イベントを指す用法が支配的であり，
   `COMPLETED_WEAK_RE` への追加候補としては原則として不適とみなす．

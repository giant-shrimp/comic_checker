## 判定1: 5要素それぞれが個別に観測可能な差を生んだか

**生んだ。** 続編・番外編・スピンオフ・外伝・次世代編の5要素すべてが、独立した
単一文フィクスチャで個別に`True→False`を示した。5要素をまとめた単一のフィクスチャ
ではなく個別のフィクスチャで確認したため、CLAUDE.mdが定める「複数ガードが同じ値を
返す場合、一つを除去しても出力が変わらない」問題（1要素が機能しなくても他要素が
拾ってしまい合格に見える問題）は、この設計では原理的に発生しない。

## 判定2: 負のコントロール6件すべてが不変だったか

**不変だった（6件すべて）。** 元の負のコントロール（リメイク版）と、追加した
5件の真の負のコントロール（後編・特別編・スピンアウト・外典・新世代作品）は、
いずれも修正前後で`_has_ongoing_signal()`の戻り値が変化しなかった。除外判定が
`SPINOFF_MARKERS`の5要素だけに反応しており、無関係な近い語を巻き込んでいないことを
示す。

## 想定される修正方針（未検証）

- 「配信終了」「連載されており」の追加は、`~/comic_checker-agent-notes/`の
  下書き（`step98_b_issue_drafts.md`）で「安全」と評価されているが、**この評価は
  `judge()`本体のveto層を反映しない手作業シミュレーションに基づくものであり、
  実judge()ハーネスでの再検証を経ていない。未検証として扱う。**
- 「連載され、」の素朴な追加は、同じ下書きで「安全ではない」（継続中を示す文を
  完結と誤認識させる新規誤判定の恐れ）と評価されているが、これも同様に
  **未検証**（同じ理由）。より狭い条件（完結convention語の近接等）の設計検討が
  必要と考えられるが、この判断自体も再検証が必要。

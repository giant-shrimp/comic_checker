# 案Bミューテーションテスト: 代替語候補の探索結果（候補ゼロ）

**実行日**: 2026-08-16
**結論を先に書く: 現コーパス（holdout99+regression61、計160行）には、下記の選定基準を
満たす代替語候補が1つも存在しなかった。基準は緩めていない。**

## 適用した選定基準（実行前に固定）

1. `MANGA_MARKERS`（"漫画","コミカライズ","コミック版","漫画版"）に含まれないこと。
   含まれると、`is_multimedia=True`の行で「メディアミックスの漫画化」文として
   別経路（`_judge_extract()`699-702行目、has_manga一致による直接return）で
   先に決着してしまう（`planb_verification_result.md`が記録した「コミカライズ」
   失敗の直接の原因）。
2. `SPINOFF_MARKERS`（既存の対象語彙）に含まれないこと。
3. 候補語を`_has_ongoing_signal()`の除外対象へ加えたとき、この関数自身
   （実装をimportした本物。正規表現の書き写しではない）の戻り値が変化する行が
   1件以上存在すること（「到達」の定義）。
4. 到達した行はすべて`is_multimedia=True`であること。追加で識別した条件:
   `is_multimedia=False`の行では、`_judge_extract()`696-697行目の直接return
   （is_multimedia分岐の外）により、SPINOFF_MARKERSタグの無い文は
   `_has_ongoing_signal()`の値と無関係に決着してしまう可能性があるため、
   この経路も「別経路で先に決着する」条件として扱った。

## ONGOING_RE一致56文の全件調査

候補選定の手がかりを広げるため、現コーパス（holdout99+regression61）で
`ONGOING_RE`（「連載中」「連載されている」）に一致する文を全件、実測で洗い出した。

**総数: 56文。**

このうち、`MANGA_MARKERS`にも`SPINOFF_MARKERS`にも一致しない文は**44文**。全件を
目視で確認した結果、いずれも「『◯◯誌』にて連載中。」のような、記事本編自身の
掲載状況を直接述べる文のみであり、**派生作品・別作品を指す語彙は一切含まれて
いなかった**。唯一やや性質が異なるのは「小説家になろうにて、2018年12月から
連載されている。」の1文だが、これは当該作品自身の原作小説自体の掲載チャネルを
述べたものであり、SPINOFF_MARKERSが想定する「本編とは別の派生作品」には該当しない。

残る12文（56−44）は、`MANGA_MARKERS`または`SPINOFF_MARKERS`のいずれかに一致する文
（`SPINOFF_MARKERS`側は`effective_hit_rate_analysis.md`が既に洗い出した5行、
`MANGA_MARKERS`側は`planb_verification_result.md`が記録した「コミカライズ」7行に
概ね対応する）。

## 結論

**現コーパスに、選定基準4つすべてを満たす代替語は存在しない。**

## この結果の含意（限界として明記する）

現コーパスにおいて、ONGOING_REと共起する「派生作品」を示す語彙は、実質的に
`SPINOFF_MARKERS`自身（5語）と`MANGA_MARKERS`絡みの「コミカライズ」表現に限られて
いた。**これは、案Bが変更する除外機構（`_has_ongoing_signal()`のSPINOFF除外）が
現コーパスで実際に作用しうる範囲が、非常に狭いことを示す実測結果である。**

裏を返せば、`SPINOFF_MARKERS`の5要素以外の「派生作品＋連載中」パターンについては、
この機構が実データでどう振る舞うかを現コーパスでは確認しようがない、という限界も
同時に意味する。番外編・外伝・次世代編（`effective_hit_rate_analysis.md`が既に
「ONGOING_REと共起する文が現コーパスに1件も無い」と記録済みの3語）だけでなく、
**それ以外のどんな派生作品語彙であっても、現コーパスにはそもそも該当する実例が
存在しない**、というより広い事実がここで確認された。

## 基準を緩めなかったことについて

基準1（MANGA_MARKERS除外）・基準4（is_multimedia=True限定）は、いずれも
「コミカライズ」の失敗から直接導いた、結果を見た後の条件である。この2条件を
満たしたうえで**候補が0件だった**という結果そのものを見てから、さらに基準を
緩めて候補を探すことは、「0件という結果に基準を合わせにいく」操作であり、
今回撤回した「コミカライズ」選定時と同型の誤り（静的走査結果に基準を後から
合わせる）を繰り返すことになる。**したがって基準は緩めず、候補ゼロという結果を
そのまま記録した。**

# コミックチェッカー 利用ガイド

Python などの準備は不要です。配布された `comic_checker.exe` をダブルクリックするだけで
使えます。このガイドは、そのアプリを使う方に向けたものです（開発する方向けの情報は
[README.md](../README.md) を参照）。

## これは何をするもの？

Excel に並んだ漫画タイトルの一覧を読み取り、それぞれが **完結**しているか
**連載中**かを日本語 Wikipedia で調べて、結果を同じ Excel に書き戻すアプリです。

- インターネットに接続していれば動きます。
- 調べた結果は、元の Excel ファイルに列を足す形で書き込まれます。
- 100 件でも 1000 件でも、一覧をまとめて自動でチェックできます。

## 1. アプリを受け取る

`comic_checker.exe` は開発者から受け取ってください（社内共有フォルダ、USB メモリ、
ファイル転送など、渡し方は問いません）。受け取った `.exe` ファイルを、デスクトップや
任意のフォルダに置けば準備完了です。**インストール作業はありません。**

> このアプリは 1 つの `.exe` ファイルだけで動きます。フォルダごと配られた場合も、
> 中の `comic_checker.exe` をそのまま使えます。

## 2. 起動する（SmartScreen 警告への対処）

`comic_checker.exe` をダブルクリックします。

初回起動時、Windows が青い画面で

> **Windows によって PC が保護されました**
> Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。

と表示することがあります。これは「発行元の署名が付いていない配布ファイル」に対して
Windows が出す**標準的な警告**で、アプリが壊れているわけではありません。次の手順で
起動できます。

1. 警告画面の **「詳細情報」** をクリックする
2. 下に現れる **「実行」** ボタンをクリックする

一度実行すれば、次回以降は警告なく起動できることが多いです。

> 警告が出ること自体は想定内です（このアプリはコード署名をしていないため）。
> どうしても不安な場合は、渡してくれた開発者にファイルが正しいものか確認してください。

## 3. Excel を準備する

チェックしたいタイトルの一覧を Excel（`.xlsx` 形式）で用意します。

- **1 行目を見出し行にし、タイトルを入れる列の見出しを「タイトル」にしてください。**
- タイトルは 1 行に 1 作品ずつ入れます。

例：

| タイトル |
|---|
| ONE PIECE |
| 進撃の巨人 |
| ダンダダン |

見出しが「タイトル」でない（例：「作品名」）場合は、そのままでは読み取れません。
見出しを「タイトル」に変えるか、開発者に相談してください。

> **開いたままだと保存できません。** アプリは処理の最後にこの Excel へ書き込みます。
> 対象の Excel ファイルは、実行前に閉じておいてください（Excel で開いたままだと、
> ファイルがロックされて保存に失敗します）。

## 4. 使う

1. アプリの上部「📁 対象ファイル」で、チェックしたい Excel を指定します。方法は 2 通り：
   - **「ファイルを選択…」ボタン**を押して選ぶ
   - ファイルを枠に**ドラッグ＆ドロップ**する（「ここに .xlsx をドラッグ＆ドロップ
     できます」と出ている場合）
2. **「▶ 実行」ボタン**を押します。
3. 「📊 進捗」欄で、進捗バーと `処理中… 3/10 件` のような表示が進みます。
4. 「📝 ログ」欄に、1 件ごとの結果（`[1/10] ONE PIECE -> 連載中 …`）が流れます。
5. 終わると「内訳」に **完結／連載中** などの件数がまとまって表示され、進捗バーが
   緑色になります。

処理が終わると、結果は**元の Excel ファイルに保存済み**です。Excel を開いて確認して
ください。

> - `.xlsx` 以外のファイルをドロップした場合は、ログにメッセージが出るだけで、
>   選択は変わりません（間違ったファイルで上書きされることはありません）。
> - 途中まで進んだところで閉じてしまっても、一定件数ごとに保存されるため、
>   そこまでの結果は残っています。もう一度実行すると、**すでに結果が入っている行は
>   飛ばして**続きから調べます。

## 5. 結果の見方

実行すると、Excel に次の列が（無ければ）追加され、結果が書き込まれます。

| 列名 | 内容 |
|---|---|
| 連載状況 | 判定結果。下の表を参照 |
| 判定方法 | どこで調べたか（通常は `Wikipedia`） |
| 判定根拠 | そう判定した根拠になった Wikipedia の一文 |
| 参照タイトル | 実際に参照した Wikipedia 記事のタイトル（合っているか確認用） |
| 参照URL | 参照した Wikipedia ページの URL |

「連載状況」に入る値の意味：

| 値 | 意味 |
|---|---|
| **完結** | 作品が完結している（打ち切りを含む。詳しくは「判定根拠」列を参照） |
| **連載中** | 現在も連載が続いている |
| **判定不能** | Wikipedia は見つかったが、完結か連載中かを確信を持って判定できなかった |
| **記事なし** | その名前の Wikipedia 記事が見つからなかった |
| **エラー** | その行の処理中に問題が起きた（次の行の処理は続行される） |

**「参照タイトル」列は必ず確認することをおすすめします。** タイトルの表記ゆれなどで、
別の作品の記事にヒットしていることがあります。参照タイトルが思っていた作品と違う
場合は、その行の判定は当てになりません。

> **「判定不能」は間違いではありません。** 原作小説とコミカライズが別々に存在する
> 作品などで、「その状況説明が漫画の話なのか原作小説の話なのか確信できない」ときに、
> 無理に決めつけず「判定不能」としています。手動で確認してください。

## 6. 困ったときは（トラブルシューティング）

### ダブルクリックしても何も起きない／すぐ消える

- ウイルス対策ソフトがブロックしている可能性があります。「2. 起動する」の SmartScreen
  対処を試してください。それでも起動しない場合は、ウイルス対策ソフトの検疫
  （隔離）フォルダに入っていないか確認してください。
- ネットワークの制限が厳しい環境では、起動はしても Wikipedia に接続できず、結果が
  すべて「記事なし」や「エラー」になることがあります。

### 「実行」を押しても「Excelファイルを選択してください」と出る

- 先に「📁 対象ファイル」でファイルを指定してください（未選択の状態では実行できません）。

### 実行するとエラーになる／すべて「エラー」になる

- 対象の **Excel ファイルを閉じてから**実行してください（開いたままだと保存に失敗
  します）。
- Excel の 1 行目の見出しに **「タイトル」列があるか**確認してください。無いと
  タイトルを読み取れません。
- インターネットに接続されているか確認してください。

### 「判定不能」や「記事なし」が多い

- **記事なし**：タイトルの表記を Wikipedia に合わせてみてください（正式名称、
  スペースや記号の有無など）。Wikipedia に記事が無い作品は判定できません。
- **判定不能**：原作と漫画が別々にある作品などで起きやすい判定です。「判定根拠」列と
  「参照URL」列を手がかりに、手動で確認してください。

### 文字が □ や豆腐のように表示される

- 日本語フォントや絵文字が用意されていない環境で起こることがありますが、動作自体には
  影響しません。見出しのアイコンが出ないだけで、機能はそのまま使えます。

### ドラッグ＆ドロップができない

- 「ファイルを選択…」ボタンからの選択は常に使えます。そちらをお使いください
  （ドラッグ＆ドロップは環境によって使えないことがあります）。

---

上記で解決しない場合は、**ログ欄に表示されている内容**を控えて、渡してくれた開発者に
共有してください。どの行で何が起きたかが分かると、原因の切り分けが早くなります。

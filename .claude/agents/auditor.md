# 監査の観点

`.claude/skills/report-self-check/SKILL.md` の手順3のチェックリストを毎回読み、
その各項目を観点とする。観点をこのファイルに書き写さない（出典を1か所にする
ため）。依頼文に記載規則が含まれていれば、それも観点に加える。

# 指摘の形式（すべて必須）

- 所在（ファイルの相対パスと行番号、または報告の見出し）
- 該当する観点（チェックリストの項目または記載規則の文言）
- 確度（確実／要確認）
- 根拠（なぜ該当するかを1文。作品名・個人名・該当行の本文を書き写さない）

所在と観点を示せない指摘はしない。指摘が無い場合は「指摘なし」と書き、確認した
観点の一覧を併記する。

リポジトリ内のファイルは、所在・監査対象・参照したファイルを含め、出力のどこでも
リポジトリのルートからの相対パスで書く。Read・Grep・Glob の結果に絶対パスが
含まれる場合は、相対パスに直してから書く。/tmp/ 以下のファイルはそのパスのまま
書いてよい。

# 書いてはいけないもの

- 修正案・採否の判断・優先順位
- 実在の作品名・個人名
- 絶対パス（/tmp/ 以下を除く）
